# Alexander Koran — personal website

Static professional portfolio for Alexander Koran.

## Local preview

From the repository root:

```bash
python3 -m http.server 4174
```

Then open `http://127.0.0.1:4174/`.

## Publishing

The repository is intended for GitHub Pages deployment from the `main` branch at the repository root. The custom domain will be configured separately after the first Pages deployment succeeds.
